# Assignment 2: Text Analyzer

**CPRO 2101 Full Stack JavaScript**

## Description

This React application analyzes text entered by the user. After submitting the text, it displays:

- **Total number of sentences** (separated by period `.`)
- **Frequency of each word** in the input text

## Setup

1. Install dependencies: `npm install`
2. Start the app: `npm start`
3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Requirements

- Created with React (version 18.2.0)
- User enters text in a text area and clicks "Analyze" to see the report.
- Submit your project as a zip file (excluding `node_modules`) using the format: `firstname_studentID.zip`.
